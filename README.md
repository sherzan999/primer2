# Шаблон сайта автосервиса (Liquid Glass)

Стеклянные поверхности, градиентный фон, блик за курсором. Эффект искажения виден только в Chromium; при включённом «уменьшить прозрачность» поверхности становятся сплошными.

Цель: вызвать доверие и помочь клиенту быстро записаться на обслуживание. Один файл `index.html`, без сборки и зависимостей.

## Структура страницы
Первый экран, услуги, преимущества, этапы работы, форма записи, контакты с картой-заглушкой, частые вопросы, подвал с соцсетями.

## Что нужно заполнить
Все недостающие данные выделены жёлтыми рамками в квадратных скобках, например `[Название автосервиса]`. Найдите их поиском по `class="todo"` и замените своими данными. В шаблоне нет выдуманных цен, отзывов, стажа и гарантий.
Также замените:
- блок «Карта-заглушка» на код карты (iframe Яндекс Карт или Google Maps);
- ссылки `data-todo` в подвале (соцсети, политика конфиденциальности) на реальные;

## Отправка формы
Форма проверяет поля, но **заявки не отправляет**, пока не задан обработчик. В конце `index.html` найдите:

```js
const FORM_ENDPOINT = "";
```

и впишите адрес обработчика (Formspree, Google Apps Script, Telegram-бот, свой сервер). Данные уходят POST-запросом в формате JSON.

## Публикация на GitHub Pages
```bash
git init && git add . && git commit -m "Шаблон сайта автосервиса"
git branch -M main
git remote add origin https://github.com/<user>/autoservice-liquid-glass.git
git push -u origin main
```
Затем: Settings → Pages → Deploy from a branch → `main` / `(root)`.
Адрес: `https://<user>.github.io/autoservice-liquid-glass/`

## Доступность
Подписи у всех полей, текстовые сообщения об ошибках, видимый фокус, ссылка «Перейти к содержимому», учёт `prefers-reduced-motion`.
